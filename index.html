Fundamental patterns (how each forced cell is proved)
Every blue (0%) or red (100%) cell on the board comes from one of the patterns below. Hover any colored cell to see which pattern applies to it. Diagrams are drawn in the same style as Insight mode: red cells are 100% mine, blue cells are 0% mine, the cell being proved carries a small ★ marker.
1. Single-clue forced mine

1
A number N has exactly N unrevealed neighbors left — every one of them must be a mine. Here the "1" has only one unrevealed neighbor, so it must be the mine.
2. Single-clue safe (satisfied clue)

1
A number N already has N mines counted among its neighbors (flags or known mines). All remaining unrevealed neighbors are safe. The flag already accounts for the "1", so the marked cell must be safe.
3. Subset difference → mine
12
Clue B's neighbors are a superset of clue A's. If B needs one more mine than A and the cells only B touches (B\A) equal that difference, every cell in B\A is a mine. Here the marked cell touches "2" but not "1" — it's the forced mine.
4. Subset difference → safe
12
Mirror of #3, applied to the smaller clue A. The marked cell touches "1" but not "2". Since "1" is satisfied by revealed neighbors, the marked cell is safe.
5. Tank / swap (equal subset)
11
Two clues with the same number touch the same count of unrevealed cells but in different shapes. The cells only the left "1" touches (including the marked cell) are mines; the cells only the right "1" touches are safe.
Beyond these — global reasoning
When no local pattern forces a cell, the solver falls back to global mine-count accounting (how many mines remain vs. how many unrevealed cells). Cells colored in the middle of the gradient (not red or blue) are those: read the number, and use the color as a rough guide.
